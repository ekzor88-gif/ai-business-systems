# Шаблоны Документов и Сайтов (Templates Repository)

## Назначение
Директория `templates/` содержит эталонные шаблоны для веб-сайта портфолио, макеты файлов README.md проектов, шаблоны профессиональных резюме и схемы стилей (CSS/Themes).

## Обязанности
- Хранение HTML, React или Astro шаблонов для веб-интерфейса портфолио.
- Предоставление разметки и стилей для экспортируемых PDF/Markdown резюме.
- Хранение структурированных Markdown шаблонов для проектных README.md.

## Будущие модули
- `website/`: Готовые шаблоны страниц (главная, проекты, контакты) и файлы стилей.
- `readme/`: Различные стили и макеты README-файлов (минималистичный, технический, бизнес-ориентированный).
- `resume/`: HTML/LaTeX шаблоны для красивого форматирования резюме.
