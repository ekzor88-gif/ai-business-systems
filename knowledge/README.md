# База Знаний (Knowledge Base & Engine)

## Назначение
Директория `knowledge/` содержит компоненты для построения, хранения и извлечения структурированных знаний о пользователе. Это локальное хранилище фактов, достижений и технологического стека, извлеченных из входных данных.

## Обязанности
- Парсинг неструктурированных источников (резюме, репозитории, тексты) в структурированный граф знаний.
- Индексация текстовых эмбеддингов для эффективного поиска по запросу (Semantic Search / RAG).
- Хранение фактологической базы данных о профессиональном опыте пользователя без дублирования.

## Будущие модули
- `parser.py`: Модули разбора PDF-резюме и исходного кода проектов.
- `indexer.py`: Процесс индексации извлеченной информации и сохранение в векторное/документное хранилище.
- `store.py`: Интерфейс взаимодействия с локальным векторным хранилищем (например, ChromaDB или FAISS) и JSON-документами.
