# Шаблоны Промптов (LLM Prompts Templates)

## Назначение
Директория `prompts/` содержит декларативные шаблоны промптов для взаимодействия с LLM-моделями. Каждый агент использует строго определенный промпт для выполнения своей задачи.

## Обязанности
- Хранение промптов в формате Markdown для улучшения читаемости.
- Применение разметки XML/Markdown внутри промптов для разделения инструкций, ограничений и контекста.
- Предотвращение галлюцинаций LLM путем внедрения строгих инструкций (например, "использовать только предоставленный контекст").

## Будущие модули
- `project_extractor.md`: Промпт для разбора кода и извлечения архитектуры и достижений.
- `readme_generator.md`: Шаблон промпта для генерации профессионального README.md проекта.
- `website_generator.md`: Инструкции для генерации контента и структуры сайта портфолио.
- `reviewer.md`: Набор инструкций для оценки качества выходных данных агентов и выявления галлюцинаций.
