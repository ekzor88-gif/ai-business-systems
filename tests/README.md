# Набор Тестов (Testing Suite)

## Назначение
Директория `tests/` содержит модульные (unit) тесты, интеграционные тесты системных конвейеров, а также сценарии тестирования ИИ-агентов с использованием заглушек (mocks).

## Обязанности
- Покрытие тестами базовой логики оркестрации и вспомогательных утилит.
- Валидация вызовов внешних API (GitHub, LLM-провайдеры) с помощью моков и VCR-записей.
- Проверка корректности работы валидаторов JSON-схем.

## Будущие модули
- `unit/`: Модульные тесты для базовых классов, парсеров и конфигураторов.
- `integration/`: Интеграционные тесты для сквозного выполнения конвейера (с мок-данными).
- `agent_tests/`: Специфические тесты для оценки ответов агентов на соответствие правилам (отсутствие галлюцинаций, следование схеме).
- `conftest.py`: Общие фикстуры для тестирования (pytest).
