# Дорожная Карта Реализации (Implementation Roadmap)

Этот документ описывает поэтапный план реализации платформы **Portfolio Factory**, разделенный на 6 ключевых вех (Milestones).

---

## Обзор Вех

| Веха | Описание | Приоритет | Статус |
| :--- | :--- | :--- | :--- |
| **Веха 1** | Архитектура и проектный скелет | Высокий | В процессе |
| **Веха 2** | Построитель Знаний (Knowledge Builder) | Высокий | Запланировано |
| **Веха 3** | Конвейер Агентов (Project Extractor & Pipeline) | Высокий | Запланировано |
| **Веха 4** | Генератор Веб-сайта (Website Generator) | Средний | Запланировано |
| **Веха 5** | GitHub Публикатор (GitHub Publisher) | Средний | Запланировано |
| **Веха 6** | Непрерывное Улучшение (Reviewer & Optimization) | Низкий | Запланировано |

---

## Детальное Описание Вех

### Веха 1: Архитектура и проектный скелет (Текущая веха)
Создание структуры каталогов, архитектурной документации, спецификаций агентов, JSON-схем взаимодействия, шаблонов промптов и конфигурационных файлов.

- **Задачи**:
  - [x] Создание структуры папок проекта.
  - [x] Написание файлов README в каждой поддиректории.
  - [x] Разработка детальной архитектурной документации с Mermaid-диаграммами.
  - [x] Разработка JSON-схем для обмена данными между агентами.
  - [x] Разработка спецификаций для 9 ИИ-агентов.
  - [x] Создание базовых конфигурационных шаблонов (settings, models, paths, agents).
- **Критерии готовности (Exit Criteria)**:
  - Все каталоги созданы.
  - Все схемы JSON синтаксически корректны.
  - Написаны базовые конфигурационные файлы YAML.
- **План проверки (Validation Plan)**:
  - Проверка корректности YAML/JSON файлов валидаторами.
  - Проверка корректности ссылок в markdown документах.

---

### Веха 2: Построитель Знаний (Knowledge Builder)
Разработка компонентов для импорта сырых пользовательских данных и построения фактологической базы знаний (`knowledge.json`).

- **Задачи**:
  - Реализация парсера PDF и Markdown резюме.
  - Разработка Git-клиента для автоматического клонирования и чтения локальных копий репозиториев.
  - Реализация парсера метаданных репозиториев (структура папок, конфигурации package.json/requirements.txt).
  - Интеграция с локальным векторным хранилищем или простым поисковым индексом для RAG.
- **Критерии готовности**:
  - Модуль парсинга корректно обрабатывает PDF/MD резюме и сохраняет данные в соответствии с `knowledge.schema.json`.
  - Реализован класс `KnowledgeStore`, поддерживающий методы добавления фактов и семантического поиска.
- **План проверки**:
  - Тестирование парсера резюме на 5 различных макетах резюме.
  - Проверка извлечения данных из тестового Python/JS репозитория.

---

### Веха 3: Конвейер Агентов (Project Extractor & Pipeline)
Реализация оркестратора и первых ключевых генеративных агентов.

- **Задачи**:
  - Создание базового класса `BaseAgent` и оркестратора выполнения графа агентов (`Orchestrator`).
  - Реализация агента `Context Manager` для инициации сессии.
  - Реализация агента `Project Extractor` для анализа исходного кода и формирования карточки проекта.
  - Реализация агента `Architecture Writer` и интеграция с генератором Mermaid-диаграмм (`Diagram Builder`).
- **Критерии готовности**:
  - Оркестратор запускает последовательность агентов и передает контекст.
  - `Project Extractor` успешно создает JSON-описание проекта на основе исходного кода.
  - Генерируются валидные Mermaid-схемы проектов.
- **План проверки**:
  - Сквозной запуск агентов на примере одного тестового проекта.
  - Валидация выходных файлов проекта на соответствие `project.schema.json`.

---

### Веха 4: Генератор Веб-сайта (Website Generator)
Разработка шаблонов оформления и сервиса генерации статических веб-страниц портфолио.

- **Задачи**:
  - Создание модульного HTML/CSS/JS шаблона для портфолио с современным дизайном (анимации, адаптивная сетка, темная тема).
  - Разработка интеграции с генератором статических сайтов (SSG) на базе Astro или Vite.
  - Реализация агента `Portfolio Generator` для трансформации накопленных JSON-данных в контент для страниц сайта.
- **Критерии готовности**:
  - Генератор генерирует готовую директорию `/output/website/`, содержащую статические HTML/CSS/JS файлы.
  - Веб-сайт корректно отображает всю информацию о проектах, достижениях и резюме.
- **План проверки**:
  - Проверка сгенерированного сайта на валидность HTML.
  - Проверка адаптивности отображения на мобильных и десктопных устройствах.

---

### Веха 5: GitHub Публикатор (GitHub Publisher)
Создание системы автоматической публикации результатов на GitHub и настройки хостинга.

- **Задачи**:
  - Реализация сервиса работы с GitHub API.
  - Разработка агента `README Generator` для записи обновленных README в репозитории проектов.
  - Написание скриптов инициализации GitHub Pages и публикации статического сайта.
- **Критерии готовности**:
  - Автоматическое создание или обновление репозитория портфолио на аккаунте пользователя GitHub.
  - Наличие сгенерированных README файлов в целевых репозиториях.
- **План проверки**:
  - Интеграционный тест с использованием тестового токена GitHub: создание временного репозитория, пуш файлов сайта и проверка доступности страницы по URL.

---

### Веха 6: Непрерывное Улучшение
Добавление контуров обратной связи, ревью результатов и оптимизация качества генерации.

- **Задачи**:
  - Реализация агента `Reviewer` для автоматического сравнения результатов с базой знаний и выявления галлюцинаций LLM.
  - Внедрение механизмов автоматической корректировки промптов при ошибках валидации схем.
  - Оптимизация расходов на токены (кэширование запросов, выбор более дешевых моделей для простых задач).
- **Критерии готовности**:
  - Исключение галлюцинаций ИИ: при обнаружении несовпадений в фактах, агент-ревьюер перезапускает шаг генерации с указанием на ошибку.
- **План проверки**:
  - Искусственное внедрение ложной информации в промпты и проверка того, что `Reviewer` успешно блокирует генерацию и отправляет ее на доработку.
