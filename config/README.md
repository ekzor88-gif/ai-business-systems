# Конфигурация Системы (System Configuration)

## Назначение
Директория `config/` хранит файлы статической конфигурации системы, настройки взаимодействия с LLM моделями, пути к локальным ресурсам и параметры развертывания.

## Обязанности
- Хранение декларативных конфигураций в формате YAML/JSON.
- Разграничение параметров окружения, настроек моделей и путей к файлам.
- Хранение ролей и температурных параметров для каждого агента.

## Будущие модули
- `settings.yaml`: Общие настройки оркестрации, лимитов API и отладки.
- `models.yaml`: Сопоставление задач и агентов с конкретными моделями (например, Claude, Gemini, GPT).
- `paths.yaml`: Определение путей к входным данным, выходным папкам, шаблонам и кэшу.
- `agents.yaml`: Конфигурация системных промптов и параметров генерации для агентов.
