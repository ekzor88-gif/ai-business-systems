# Руководство по Разработке (Development Guide)

В данном документе приведены стандарты разработки, правила настройки окружения, требования к коду и линтингу для проекта **Portfolio Factory**.

---

## Требования к Окружению
- **Python**: Версия 3.10 или выше.
- **Node.js**: Версия 18.x или выше (необходима для работы Website Generator и Mermaid CLI).
- **Git**: Установленный в системе для клонирования целевых репозиториев.

---

## Быстрая Настройка (Локально)

```bash
# 1. Клонирование репозитория
git clone https://github.com/username/portfolio_factory.git
cd portfolio_factory

# 2. Настройка виртуального окружения Python
python -m venv .venv
source .venv/bin/activate  # Для Windows: .venv\Scripts\activate
pip install -r requirements.txt

# 3. Установка Node.js зависимостей для сборщика сайтов
npm install
```

## Настройка Переменных Окружения
Создайте файл `.env` в корне проекта на основе шаблона `.env.example`:

```env
# API Ключи для работы с LLM моделями
GEMINI_API_KEY=your_gemini_api_key
ANTHROPIC_API_KEY=your_anthropic_api_key
OPENAI_API_KEY=your_openai_api_key

# GitHub Токен (требуется доступ к репозиториям и GitHub Pages)

# Настройки отладки
DEBUG=True
LOG_LEVEL=DEBUG
```

## Стандарты Кодирования

### 1. Чистота Кода и Архитектура
- **Single Responsibility**: Каждый класс/модуль решает только одну задачу. Не допускается смешивание логики парсинга файлов с логикой обращения к LLM.
- **Интерфейсы и Контракты**: Новые агенты должны наследоваться от `core.base_agent.BaseAgent` и реализовывать метод `execute()`.
- **Типизация**: Обязательное использование аннотаций типов Python (type hinting) во всех сигнатурах функций и методов.

### 2. Форматирование Кода и Линтеры
В проекте используются следующие инструменты для поддержания единого стиля кода:
- **Black**: Для автоматического форматирования Python-кода (длина строки — 100 символов).
- **Ruff**: Для быстрого статического анализа и линтинга.
- **mypy**: Для строгой проверки статической типизации.

Запуск линтеров перед коммитом:
```bash
# Проверка стиля кода
ruff check .
black --check .
mypy .
```

## Разработка Новых Агентов

Чтобы добавить нового агента в конвейер:
1.  Опишите спецификацию агента в `docs/agents/<name>.md`.
2.  Создайте схему выходных данных в `schemas/<name>.schema.json`.
3.  Создайте шаблон промпта в `prompts/<name>.md`.
4.  Реализуйте класс агента в `agents/<name>.py`, унаследовав его от `BaseAgent`.
5.  Зарегистрируйте агента в `config/agents.yaml`.
6.  Напишите модульный тест в `tests/agent_tests/test_<name>.py`.
