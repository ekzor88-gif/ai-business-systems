# Примеры Входных и Выходных Данных (Examples)

## Назначение
Директория `examples/` служит для демонстрации возможностей системы. Здесь собраны примеры исходных файлов пользователя (резюме, исходный код проектов) и результатов работы платформы.

## Обязанности
- Предоставление разработчикам тестовых наборов данных для отладки локального запуска.
- Демонстрация ожидаемого формата резюме, описаний проектов и структуры репозиториев.
- Хранение эталонных сгенерированных портфолио, сайтов и README-файлов для визуального сравнения.

## Будущие модули
- `resumes/`: Примеры резюме в различных форматах (PDF, Markdown, JSON).
- `project_descriptions/`: Шаблоны и примеры текстовых описаний проектов от пользователя.
- `generated_portfolios/`: Примеры успешно собранных сайтов-портфолио.
- `generated_readmes/`: Примеры README-файлов для GitHub.
