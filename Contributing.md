# Руководство по Участию в Разработке (Contributing Guide)

Мы рады вашему интересу к развитию **Portfolio Factory**! Этот проект задуман как профессиональная, расширяемая мультиагентная платформа с открытым исходным кодом, и ваш вклад поможет сделать ее еще лучше.

---

## Процесс Разработки (Workflow)

1.  **Создание Issue**: Перед началом работы над любой задачей (исправление бага, новая фича или агент) создайте соответствующую задачу в GitHub Issues для обсуждения архитектурного решения.
2.  **Форк и Ветки**: Создайте форк репозитория и ветку от `main` с понятным именем:
    - `feature/agent-readme-generator`
    - `bugfix/issue-json-parsing`
    - `docs/update-architecture`
3.  **Локальная разработка**: Следуйте правилам, описанным в [Development.md](file:///c:/projects/portfolio_factory/Development.md).
4.  **Тестирование**: Перед отправкой Pull Request убедитесь, что все тесты проходят:
    ```bash
    pytest
    ```
5.  **Создание Pull Request (PR)**:
    - Убедитесь, что ваш PR содержит четкое описание изменений.
    - Свяжите PR с соответствующим Issue.
    - Все новые агенты или модули *обязаны* сопровождаться тестами и документацией.

---

## Архитектурные Требования к Вкладу

Для сохранения чистоты кодовой базы и предотвращения превращения проекта в спагетти-код, мы строго следим за соблюдением следующих правил:
- **Никаких гигантских скриптов**: Если функция занимает более 100 строк кода, разбейте ее на подмодули.
- **Никаких галлюцинаций ИИ**: Все промпты и агенты должны работать строго на базе переданного контекста. Промпты должны проходить обязательное ревью на предмет устойчивости к галлюцинациям.
- **Соответствие JSON-схемам**: Любой обмен данными между компонентами системы должен быть типизирован и описан схемой в директории `schemas/`.

---

## Правила Оформления Коммитов (Conventional Commits)

Мы используем стандарт Conventional Commits для автоматического ведения списка изменений:
- `feat(agent): добавить агента Diagram Builder`
- `fix(parser): исправить извлечение PDF метаданных`
- `docs(arch): обновить схему базы знаний`
- `test(core): добавить тесты для оркестратора`

Спасибо, что делаете Portfolio Factory лучше!
