# Внешние Сервисы и Интеграции (Services Integration)

## Назначение
Директория `services/` объединяет сторонние сервисы, модули интеграции с внешними API (GitHub, генерация диаграмм) и движки сборки статических сайтов.

## Обязанности
- Изоляция интеграционного кода с внешними сервисами.
- Предоставление стандартизованных интерфейсов (клиентов) для отправки данных, деплоя и рендеринга.
- Управление авторизацией и токенами доступа для внешних API.

## Будущие модули
- `github/`: Поддиректория для интеграции с API GitHub (создание репозиториев, коммиты, деплой на GitHub Pages).
- `diagrams/`: Сервис генерации архитектурных диаграмм (рендеринг Mermaid/Graphviz схем в SVG/PNG).
- `website/`: Интеграция с генератором статических сайтов (SSG) для сборки финального портфолио.
