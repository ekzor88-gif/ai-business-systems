# Генератор Архитектурных Диаграмм (Diagrams Service)

## Назначение
Директория `services/diagrams/` содержит интеграцию со средствами автоматической генерации архитектурных диаграмм и визуализации связей компонентов на основе Mermaid, Graphviz или PlantUML.

## Обязанности
- Рендеринг текстового описания диаграмм (Mermaid/PlantUML) в графические форматы (SVG, PNG).
- Валидация синтаксиса сгенерированных LLM архитектурных описаний перед рендерингом.
- Интеграция с локальными CLI утилитами (например, `@mermaid-js/mermaid-cli`) или внешними API-рендерерами (Kroki, PlantUML Server).

## Будущие модули
- `renderer.py`: Модуль вызова CLI/API для конвертации текста диаграммы в изображение.
- `validator.py`: Парсер синтаксиса Mermaid/Graphviz для обнаружения ошибок до этапа сборки.
- `formatter.py`: Адаптер для стилизации диаграмм под общую цветовую тему сайта портфолио.
