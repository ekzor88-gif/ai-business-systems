# Интеграция с GitHub (GitHub Service)

## Назначение
Директория `services/github/` содержит клиент для работы с GitHub API, логику клонирования/анализа репозиториев пользователя и скрипты автоматической публикации портфолио в GitHub Pages.

## Обязанности
- Авторизация с использованием персональных токенов доступа (GitHub PAT) или OAuth.
- Чтение кода репозиториев, коммитов и pull request'ов для анализа опыта.
- Запись сгенерированных README.md обратно в репозитории пользователя.
- Создание репозитория портфолио и запуск GitHub Actions для сборки и деплоя на GitHub Pages.

## Будущие модули
- `client.py`: Базовый клиент для отправки REST/GraphQL запросов к GitHub API.
- `repo_manager.py`: Логика клонирования, создания веток и отправки коммитов.
- `publisher.py`: Скрипты инициализации GitHub Pages и проверки статуса деплоя.
