# Движок Сборки Сайта-Портфолио (Website Service)

## Назначение
Директория `services/website/` содержит логику рендеринга и сборки статического сайта-портфолио на основе шаблонов и структурированных данных об опыте пользователя.

## Обязанности
- Генерация статических HTML/CSS страниц из структурированных JSON/YAML файлов данных.
- Интеграция с современными инструментами сборки (например, Vite, Next.js, Astro или 11ty).
- Настройка путей, оптимизация картинок (включая сгенерированные диаграммы) и минификация ресурсов.

## Будущие модули
- `builder.py`: Модуль управления жизненным циклом сборки сайта (копирование ресурсов, вызов SSG-компилятора).
- `data_injector.py`: Скрипт внедрения сгенерированных агентами данных в контекст веб-шаблона.
- `assets_optimizer.py`: Утилита для сжатия изображений и конвертации SVG диаграмм.
