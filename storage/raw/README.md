# Входные Данные Пользователя (User Input)

## Назначение
Директория `input/` является точкой входа для пользовательских данных. Сюда помещаются исходные материалы, на основе которых система будет генерировать портфолио.

## Обязанности
- Хранение оригинальных файлов резюме пользователя (в форматах PDF, DOCX, TXT или MD).
- Хранение локальных копий описаний проектов и конфигурационных файлов пользователя.
- Хранение ссылок или метаданных для доступа к внешним репозиториям GitHub.

## Будущие модули
- `resume.pdf` / `resume.md`: Файл резюме, подлежащий парсингу.
- `projects.json`: Список ссылок на репозитории GitHub и краткие описания проектов.
- `profile.yaml`: Дополнительные пользовательские настройки (например, желаемые акценты в портфолио, контактные данные).
