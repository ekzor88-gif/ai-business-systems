## 📋 О проекте

**Green Leaf AI Bot** — это AI-консультант для сетевой компании в сфере wellness-продукции, реализованный как Telegram-бот. Бот полностью заменяет работу менеджера-консультанта: он ведёт диалог с клиентом, понимает запросы на естественном языке, находит подходящие товары в каталоге из 380+ позиций и формирует персонализированные рекомендации.

### Проблема, которую решает проект

Компания работает по модели сетевого маркетинга: партнёры привлекают клиентов и консультируют их по продукции. Основные боли:

- **Партнёры тратят часы** на одни и те же вопросы: «Что у вас есть для иммунитета?», «Какой крем подойдёт для сухой кожи?»
- **Каталог из 380+ товаров** — невозможно держать в голове все позиции, ингредиенты и рекомендации
- **Целевая аудитория 40+** — людям сложно пользоваться сайтами и приложениями; Telegram — минимальный порог входа
- **Партнёры теряют клиентов**, если не могут ответить быстро

### Решение

Бот берёт на себя роль круглосуточного AI-консультанта:
- Клиент описывает проблему или запрос текстом → бот находит релевантные товары
- Каждый партнёр получает **персональную реферальную ссылку** — клиенты автоматически привязываются к «своему» партнёру
- Партнёр видит, что его клиенты ищут, и может подключиться к диалогу в нужный момент

## 🔍 Как работает поиск (RAG-pipeline)

Поиск реализован по принципу **Retrieval-Augmented Generation (RAG)** — гибридная модель, сочетающая точный и семантический поиск:

### Этап 1: Индексация каталога
1. Каталог загружается из `.docx` файла (автоматический парсинг таблиц)
2. Для каждого товара LLM генерирует **поисковые теги** (ингредиенты, категория, решаемая проблема)
3. Текст товара разбивается на **чанки** (фрагменты): название, описание, каждый тег отдельно
4. Каждый чанк преобразуется в **вектор** (embedding) размерностью 1536
5. Все данные и векторы сохраняются в PostgreSQL с расширением pgvector

### Этап 2: Обработка запроса пользователя
1. **Keyword Search** — прямой поиск по вхождению слов в названиях и тегах
2. **Semantic Search** — запрос пользователя → вектор → cosine similarity → топ-N релевантных чанков
3. Результаты объединяются и дедуплицируются
4. Контекст передаётся в GPT-4o-mini, который формирует персонализированный ответ

## 💰 Юнит-экономика и бизнес-модель

### Модель монетизации

Бот работает по модели **B2B SaaS с партнёрскими подписками**:
- Партнёр оплачивает подписку → получает реферальную ссылку → привлекает клиентов
- Клиенты партнёра получают доступ к AI-консультанту бесплатно
- При истечении подписки партнёра — доступ блокируется для всех его клиентов

### Структура расходов (оценка на текущих объёмах)

| Статья | Стоимость/мес |
|---|---|
| Hetzner Cloud (VPS) | ~€5–10 |

| Supabase (Free/Pro) | $0–25 |

## 🔧 Ключевые компоненты системы

### 1. `bot.py` — Ядро бота
- Обработка всех типов сообщений и callback-кнопок
- **AccessMiddleware** — проверка подписки на уровне middleware (партнёр → клиенты)
- Реферальная система: deep-link авторизация через `?start=REFERRAL_CODE`
- Асинхронная архитектура на `asyncio`

### 2. `db.py` — Слой данных
- CRUD-операции для пользователей, товаров, сообщений
- Гибридный поиск: keyword + semantic (pgvector)
- Управление партнёрскими подписками и доступом
- Автоматическая привязка клиентов к партнёрам

### 3. `llm.py` — AI-движок
- Продвинутый системный промт с правилами поведения консультанта
- Контекстные ответы на основе RAG-результатов
- Защита от «галлюцинаций»: бот отвечает только по данным каталога

### 4. `embeddings.py` — Векторный движок
- Генерация поисковых тегов через GPT-3.5-turbo
- Создание и управление эмбеддингами (text-embedding-3-small)
- Batch-обработка и backfill для массового обновления каталога

### 5. CI/CD Pipeline
- Push в `main` → GitHub Actions → SSH Deploy на Hetzner
- Docker-контейнеризация для стабильного окружения
- Zero-downtime деплой через `docker compose up --build -d`
