# Ядро Системы (Core System)

## Назначение
Директория `core/` содержит базовые абстракции системы, оркестратор агентного конвейера, механизмы логирования, телеметрии и обработки ошибок. Это фундамент платформы Portfolio Factory.

## Обязанности
- Определение базовых классов и интерфейсов для агентов (`BaseAgent`), сервисов и хранилищ.
- Реализация циклов выполнения и координации агентов (оркестрация пайплайна).
- Централизованная обработка системных исключений и механизм повторных попыток (retries).
- Сбор метрик, аудит токенов и телеметрия LLM-запросов.

## Будущие модули
- `orchestrator.py`: Главный управляющий конвейером модуль, запускающий агентов в нужной последовательности.
- `base_agent.py`: Абстрактный класс ИИ-агента с методами отправки запросов, форматирования и валидации.
- `telemetry.py`: Инструменты для подсчета затрат токенов, замера времени выполнения и трассировки вызовов.
- `exceptions.py`: Базовые классы ошибок (например, `AgentException`, `ValidationError`, `ProviderRateLimitException`).
