# Модуль Агентов (Agents Module)

## Назначение
Директория `agents/` содержит определения отдельных ИИ-агентов, их внутреннюю логику инициализации, обработчики состояний и специфические для агентов вспомогательные инструменты.

## Обязанности
- Реализация классов агентов, наследующих от базового класса `BaseAgent`.
- Обработка жизненного цикла агента (инициализация, выполнение шага, обработка ошибок).
- Управление локальной памятью и контекстом конкретного агента во время его работы.

## Будущие модули
- `context_manager.py`: Реализация агента управления контекстом сессии.
- `project_extractor.py`: Логика агента извлечения проектов и достижений.
- `resume_writer.py`: Модуль генерации профессиональных резюме.
- `architecture_writer.py`: Модуль анализа архитектуры репозитория и создания архитектурных спецификаций.
- `diagram_builder.py`: Модуль визуализации архитектурных диаграмм.
- `readme_generator.py`: Логика создания README для репозиториев проектов.
- `portfolio_generator.py`: Модуль сборки структуры сайта портфолио.
- `reviewer.py`: Агент контроля качества и валидации выходных данных других агентов.
- `publisher.py`: Агент публикации в GitHub Pages.
