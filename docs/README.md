# Документация Проекта (Project Documentation)

## Назначение
Директория `docs/` содержит спецификации, руководства, архитектурные схемы и другие текстовые ресурсы, описывающие внутреннее устройство, дорожную карту развития и стандарты разработки системы Portfolio Factory.

## Обязанности
- Систематизация знаний об архитектуре системы и принципах взаимодействия ее компонентов.
- Хранение спецификаций и подробных контрактов каждого агента.
- Описание процессов контрибьютинга, тестирования и развертывания.

## Будущие модули
- `Architecture.md`: Системная архитектура, диаграммы потоков данных и взаимодействия компонентов.
- `Roadmap.md`: Дорожная карта с описанием вех и этапов разработки.
- `Agents.md`: Обзор агентного конвейера и принципов работы мультиагентных систем.
- `Development.md`: Инструкции по локальной настройке окружения и запуску системы.
- `agents/`: Подкаталог, содержащий индивидуальные спецификации для каждого агента (Context Manager, Project Extractor и др.).
