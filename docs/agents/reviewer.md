# Агент: Reviewer (Контролер Качества / Валидатор)

## Цель
Reviewer является главным аудитором качества системы. Он проверяет сгенерированные другими агентами тексты, README и структуру портфолио на предмет достоверности, отсутствия галлюцинаций, грамматических ошибок и строгого соответствия исходным фактам о разработчике.

## Входные данные
- Исходная фактологическая база знаний `knowledge.json`.
- Сгенерированные артефакты (`resume.json`, `projects.json`, `README.md`).
- Правила валидации (правила исключения галлюцинаций, требования к качеству текстов).

## Выходные данные
- Вердикт о прохождении проверки (Утверждено / Отклонено).
- Подробный лог замечаний в случае отклонения, с указанием конкретных несоответствий или ошибок (например, "Проект X приписывает использование Docker, но в репозитории нет Dockerfile и в knowledge.json Docker не упоминается").

## Обязанности
- Кросс-верификация фактов: сопоставление всех утверждений в сгенерированных резюме и README с исходными данными из базы знаний.
- Обнаружение галлюцинаций LLM (приписывание технологий, не существовавших в коде или резюме, преувеличение числовых показателей достижений).
- Проверка орфографии, грамматики и стиля изложения.
- Формирование отчета для оркестратора для запуска корректирующего цикла генерации (self-correction loop).

## Будущие улучшения
- Семантическое сравнение текстов с использованием эмбеддингов для обнаружения тонких логических неточностей.
- Создание базы "типичных ошибок" для оптимизации системных промптов в рантайме.
- Поддержка интеграции с внешними линтерами текста (например, LanguageTool API).
