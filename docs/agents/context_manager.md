# Агент: Context Manager (Менеджер Контекста)

## Цель
Context Manager отвечает за первичный сбор пользовательских данных, агрегацию фактов о профессиональном опыте инженера и построение начальной базы знаний (`knowledge.json`). Он координирует подготовку сессионного контекста для последующих агентов в пайплайне.

## Входные данные
- PDF или Markdown файл резюме пользователя (`input/resume.pdf` или `input/resume.md`).
- Ссылки на публичные/приватные репозитории GitHub и опциональные текстовые описания проектов от пользователя.
- Глобальная конфигурация путей и системные настройки.

## Выходные данные
- Структурированный файл `knowledge.json`, соответствующий [knowledge.schema.json](file:///c:/projects/portfolio_factory/schemas/knowledge.schema.json), содержащий:
  - Персональные и контактные данные.
  - Список извлеченных фактов об опыте работы и образовании.
  - Агрегированный перечень заявленных навыков и технологий.
  - Карту целевых репозиториев для анализа.

## Обязанности
- Извлечение неструктурированного текста из PDF-документов резюме с использованием специализированных парсеров.
- Группировка и фильтрация сырого текста по смысловым блокам (Опыт, Образование, Проекты, Навыки).
- Синтаксический анализ сырых ссылок на GitHub и проверка их доступности.
- Формирование начального слепка базы знаний пользователя без дублирования информации.

## Будущие улучшения
- Интеграция с LinkedIn API для автоматического импорта профиля пользователя.
- Реализация интерактивного CLI-интерфейса для уточнения пропущенных контактных данных или нечетких формулировок в резюме.
- Поддержка многоязычного парсинга резюме с автоматическим переводом на целевой язык портфолио.
