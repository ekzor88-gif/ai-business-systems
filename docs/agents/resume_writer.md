# Агент: Resume Writer (Составитель Резюме)

## Цель
Resume Writer преобразует структурированную информацию об опыте, навыках и проектах в лаконичное, профессиональное и ориентированное на результат (impact-driven) резюме в формате Markdown/JSON.

## Входные данные
- Структурированные файлы данных пользователя: `knowledge.json` и извлеченные проекты `projects.json`.
- Желаемый формат вывода (например, одностраничное резюме, расширенное резюме) и целевая вакансия (опционально).

## Выходные данные
- Структурированное резюме в формате JSON, соответствующее [resume.schema.json](file:///c:/projects/portfolio_factory/schemas/resume.schema.json).
- Отформатированный Markdown-файл резюме, готовый для конвертации в PDF.

## Обязанности
- Формулирование опыта работы в соответствии с методологией XYZ (Выполнил [X], что измеряется [Y], путем внедрения [Z]).
- Классификация технических навыков по категориям (Языки, Фреймворки, Базы Данных, Инструменты).
- Сокращение избыточных описаний опыта и фокусировка на измеримых достижениях для соблюдения лимитов страниц.
- Адаптация описаний под требования современных систем автоматического скрининга резюме (ATS-friendly phrasing).

## Будущие улучшения
- Интеграция с OpenAI/Gemini для автоматической адаптации (tailoring) резюме под конкретное описание вакансии (Job Description) работодателя.
- Поддержка генерации резюме на нескольких языках с сохранением профессиональной терминологии.
- Автоматический экспорт в форматы DOCX, PDF и HTML с использованием предустановленных шаблонов оформления.
