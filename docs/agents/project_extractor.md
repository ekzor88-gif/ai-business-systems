# Агент: Project Extractor (Экстрактор Проектов)

## Цель
Project Extractor анализирует исходный код целевых репозиториев разработчика и структурированные данные от Context Manager с целью извлечения детальных технических характеристик проектов, архитектуры и измеримых достижений инженера.

## Входные данные
- Файл базы знаний пользователя `knowledge.json`.
- Локальные копии репозиториев (исходный код, файлы конфигурации сборки, логи коммитов).
- Спецификация JSON-схемы проекта.

## Выходные данные
- Структурированный массив описаний проектов в формате JSON, соответствующий [project.schema.json](file:///c:/projects/portfolio_factory/schemas/project.schema.json), содержащий:
  - Имя проекта, описание и роль инженера.
  - Подробный стек технологий (библиотеки, фреймворки, СУБД, DevOps-инструменты).
  - Список извлеченных измеримых достижений (метрики производительности, оптимизация, масштаб системы).
  - Ссылки на ключевые файлы исходного кода, подтверждающие опыт.

## Обязанности
- Статический анализ структуры каталогов репозитория для автоматического определения типа проекта (например, Python/Django web app, JS/React SPA, Go microservice).
- Анализ файлов конфигурации зависимостей (например, `package.json`, `requirements.txt`, `go.mod`, `pom.xml`) для выявления точного технологического стека.
- Анализ сообщений коммитов (commit logs) и PR-описаний для выявления вклада разработчика и конкретных решенных задач.
- Поиск в кодовой базе и текстах упоминаний метрик оптимизации (например, "снижение задержки на 30%", "увеличение RPS до 5000").

## Будущие улучшения
- Семантический поиск по кодовой базе (Semantic Code Search) с использованием векторных эмбеддингов для точечного поиска сложных архитектурных решений.
- Интеграция с Git-статистикой для автоматического расчета процента вклада (line contribution) и частоты коммитов.
- Поддержка глубокого парсинга Docker-файлов и CI/CD пайплайнов (GitHub Actions, GitLab CI) для точного извлечения DevOps-опыта.
