# Агент: Portfolio Generator (Генератор Портфолио)

## Цель
Portfolio Generator агрегирует все сгенерированные текстовые, графические и структурные материалы (резюме, проекты, диаграммы) и формирует единую структуру данных в формате JSON для последующей передачи в Website Generator.

## Входные данные
- Финальная база знаний `knowledge.json`.
- Массив извлеченных проектов `projects.json`.
- Сгенерированное резюме `resume.json`.
- Пути к графическим файлам диаграмм.

## Выходные данные
- Единый структурированный файл данных портфолио `portfolio.json`, соответствующий [portfolio.schema.json](file:///c:/projects/portfolio_factory/schemas/portfolio.schema.json), готовый для инжектирования в статический сайт.

## Обязанности
- Группировка проектов по категориям или уровню сложности для удобного отображения в интерфейсе.
- Сопоставление проектов с конкретными навыками (выстраивание связей "Навык -> Применение в проекте").
- Генерация мета-тегов SEO для будущего сайта (заголовки, описания, ключевые слова).
- Формирование навигационной структуры сайта и связей страниц.

## Будущие улучшения
- Добавление аналитики для отслеживания просмотров сайта (интеграция Google Analytics или Umami).
- Поддержка гибкой настройки разделов портфолио (например, добавление разделов "Блог", "Сертификаты", "Выступления").
- Автоматическая группировка проектов по отраслям (FinTech, E-commerce, AI/ML) для таргетированного поиска вакансий.
