# Агент: Publisher (Публикатор)

## Цель
Publisher завершает работу пайплайна, выполняя физическое развертывание собранного сайта портфолио на платформе GitHub Pages и обновление README в репозиториях проектов пользователя.

## Входные данные
- Директория сгенерированного сайта `output/website/`.
- Сгенерированные файлы README.md для проектов.
- Конфигурационный файл настроек `config/settings.yaml` (токены, пути публикации).

## Выходные данные
- Лог успешного коммита и пуша изменений на GitHub.
- Публичный URL-адрес развернутого портфолио (например, `https://username.github.io/portfolio`).

## Обязанности
- Автоматическая инициализация локального Git-репозитория в папке собранного сайта, если он не был инициализирован.
- Настройка ветки `gh-pages` или создание файла конфигурации GitHub Actions для сборки.
- Отправка коммитов в удаленный репозиторий GitHub с использованием предоставленного токена.
- Публикация обновленных файлов README.md в соответствующие репозитории проектов пользователя.

## Будущие улучшения
- Поддержка развертывания на альтернативных облачных платформах (Vercel, Netlify, Cloudflare Pages).
- Автоматическая привязка кастомного доменного имени (Custom Domain) для сайта портфолио на основе настроек пользователя.
- Интеграция с Telegram-ботом или Email-оповещением для отправки уведомлений об успешном обновлении сайта.
