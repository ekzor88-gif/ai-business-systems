# Агент: README Generator (Генератор README)

## Цель
README Generator автоматически создает профессиональные, структурированные и технически точные файлы README.md для репозиториев проектов, помогая работодателям и сообществу быстро понять суть разработки.

## Входные данные
- Системный JSON-артефакт описания проекта `projects.json`.
- Архитектурное описание проекта и Mermaid-диаграммы.
- Шаблон README.md из директории `templates/`.

## Выходные данные
- Готовый файл `README.md` в формате Markdown для целевого репозитория, включающий:
  - Четкий заголовок, краткое описание (Value Proposition) и скриншот/логотип (заглушка).
  - Спецификацию ключевых функций (Features).
  - Раздел с архитектурой системы (включая Mermaid диаграмму).
  - Детальные инструкции по локальной установке, настройке переменных окружения и запуску.
  - Описание тестов и способов их запуска.

## Обязанности
- Формирование структурированного README в строгом соответствии с выбранным шаблоном.
- Автоматическое выявление и документирование необходимых переменных окружения (`.env.example`) и зависимостей.
- Создание понятных инструкций запуска (Quick Start) для различных операционных систем.
- Интеграция Mermaid-диаграмм в разметку Markdown (с использованием ссылок на SVG-файлы или блоков кода Mermaid).

## Будущие улучшения
- Автоматическая вставка бейджей статуса сборки (build badges), покрытия тестами и версий пакетов.
- Поддержка генерации интерактивных API-спецификаций (Swagger/OpenAPI плагины) прямо в README.
- Разработка механизма многоязычных файлов README (например, `README.md` и `README.ru.md`).
