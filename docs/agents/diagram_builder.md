# Агент: Diagram Builder (Построитель Диаграмм)

## Цель
Diagram Builder преобразует текстовое описание архитектуры и потоков данных от Architecture Writer в синтаксически корректный и визуально структурированный код диаграмм в формате Mermaid.

## Входные данные
- Архитектурное описание проекта от Architecture Writer.
- Спецификация поддерживаемых типов диаграмм (например, Sequence diagram, Flowchart, ER diagram).

## Выходные данные
- Текстовый файл с кодом диаграмм в формате Mermaid.
- Инструкция для вызова рендерера для преобразования кода диаграммы в SVG/PNG.

## Обязанности
- Генерация Mermaid-кода для структурных диаграмм компонентов (Flowchart) и сценариев взаимодействия (Sequence diagram).
- Валидация синтаксиса Mermaid перед сохранением файла (проверка скобок, стрелок, названий сущностей).
- Настройка единого визуального стиля и цветовой темы диаграмм для интеграции с веб-сайтом портфолио.

## Будущие улучшения
- Поддержка генерации диаграмм сущностей базы данных (ERD) на основе анализа DDL-скриптов и моделей ORM (SQLAlchemy, Prisma, Hibernate).
- Автоматическая группировка компонентов (subgraphs) для отображения Docker-контейнеров или пространств имен Kubernetes.
- Интеграция с PlantUML и Graphviz (DOT-файлы) для поддержки более сложных корпоративных архитектурных диаграмм.
