# Агент: Architecture Writer (Архитектурный Аналитик)

## Цель
Architecture Writer анализирует структуру репозитория и исходный код для создания подробного технического описания системной архитектуры проектов, включая потоки данных, ключевые паттерны проектирования и интеграции с внешними сервисами.

## Входные данные
- Структурированное описание проектов `projects.json`.
- Дерево исходного кода репозитория и ключевые конфигурации систем (например, `docker-compose.yml`, архитектурные манифесты).
- Примеры архитектурных паттернов для анализа.

## Выходные данные
- Технический документ с описанием архитектуры проекта в текстовом формате Markdown, содержащий:
  - Описание архитектурного паттерна (микросервисы, монолит, слоистая архитектура Clean Architecture/Hexagonal).
  - Описание потоков данных (Data Flow) и интерфейсов взаимодействия (REST, gRPC, очереди сообщений).
  - Обоснование выбора ключевых технологий и компонентов.

## Обязанности
- Анализ взаимосвязей между компонентами кодовой базы (вызовы функций, импорты модулей) для определения границ подсистем.
- Определение паттернов проектирования на основе структуры классов и каталогов (например, MVC, CQRS, Repository).
- Описание сетевого взаимодействия и интеграций со сторонними сервисами (базы данных, кэши, платежные шлюзы).

## Будущие улучшения
- Автоматический расчет архитектурного долга (architectural debt) и выявление узких мест в архитектуре.
- Генерация рекомендаций по оптимизации и масштабированию системы на основе лучших практик.
- Поддержка глубокого анализа облачных конфигураций (Terraform, Kubernetes манифесты) для описания инфраструктуры.
