# Вспомогательные Скрипты (Automation Scripts)

## Назначение
Директория `scripts/` содержит скрипты автоматизации для локальной разработки, сборки, деплоя, валидации схем и инициализации окружения.

## Обязанности
- Автоматизация рутинных задач разработки (форматирование, линтинг, запуск тестов).
- Предоставление утилит для быстрой ручной проверки промптов или схем.
- Подготовка дистрибутивов и скрипты CI/CD.

## Будущие модули
- `setup.sh` / `setup.ps1`: Скрипты инициализации виртуального окружения и установки зависимостей.
- `validate_schemas.py`: Скрипт для валидации тестовых JSON-файлов на соответствие JSON-схемам.
- `deploy_pages.py`: Скрипт-обертка для ручной публикации сайта портфолио.
