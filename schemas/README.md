# Контракты Данных (JSON Schemas)

## Назначение
Директория `schemas/` содержит файлы JSON Schema, описывающие жесткие контракты данных, используемые для обмена информацией между агентами и сервисами системы.

## Обязанности
- Декларативное описание структуры обмена данными (проекты, резюме, портфолио, база знаний).
- Валидация входных и выходных данных агентов на соответствие схемам.
- Обеспечение слабой связанности (loose coupling) и независимости модулей за счет стандартизации интерфейсов обмена.

## Будущие модули
- `resume.schema.json`: Контракт структуры распарсенного резюме пользователя.
- `project.schema.json`: Схема извлеченных данных проекта и достижений.
- `knowledge.schema.json`: Структура связей и узлов базы знаний.
- `portfolio.schema.json`: Контракт структуры данных для генератора веб-сайта.
