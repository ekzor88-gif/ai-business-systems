# Логирование Выполнения (Execution Logs)

## Назначение
Директория `logs/` предназначена для записи детализированной информации о работе системы, трассировки вызовов API, ошибок выполнения и отладочных сообщений.

## Обязанности
- Хранение текстовых логов работы оркестратора и отдельных агентов.
- Разделение логов по уровням критичности (DEBUG, INFO, WARNING, ERROR).
- Запись дампов запросов и ответов LLM-моделей для последующей отладки и тюнинга промптов.

## Будущие модули
- `orchestrator.log`: Лог выполнения основного пайплайна оркестратора.
- `agents.log`: Лог запросов и ответов отдельных ИИ-агентов.
- `system_errors.log`: Лог критических сбоев и исключений.
