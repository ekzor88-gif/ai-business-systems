# Модуль Проектов (Projects Module)

## Назначение
Директория `projects/` отвечает за обработку информации о конкретных проектах пользователя: парсинг исходного кода репозиториев, структурирование описаний и извлечение измеримых метрик.

## Обязанности
- Извлечение структуры директорий и ключевых файлов из репозиториев проектов (GitHub или локальных).
- Идентификация используемого стека технологий, паттернов проектирования и библиотек.
- Форматирование данных проекта по единой схеме (`project.schema.json`).

## Будущие модули
- `analyzer.py`: Модуль статического анализа репозитория для выявления технологий и архитектуры.
- `metrics_extractor.py`: Логика поиска и структурирования метрик (производительность, масштабирование, бизнес-показатели).
- `project_model.py`: Классы данных, описывающие сущность "Проект".
