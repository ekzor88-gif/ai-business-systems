# Выходные Артефакты (Output Artifacts)

## Назначение
Директория `output/` содержит сгенерированные системой артефакты: структурированные файлы резюме, обновленные README для репозиториев, архитектурные диаграммы и полностью собранный сайт портфолио.

## Обязанности
- Хранение финальных версий сгенерированных документов (Markdown, HTML, JSON).
- Структурирование файлов сайта портфолио, готовых к публикации.
- Предоставление доступа внешним сервисам (например, GitHub Publisher) к результатам генерации.

## Будущие модули
- `resume/`: Сгенерированные профессиональные резюме в различных форматах.
- `website/`: Веб-сайт портфолио (статический HTML/JS/CSS или собранное React/Next.js приложение).
- `diagrams/`: Сгенерированные архитектурные схемы проектов (SVG, PNG).
- `readmes/`: Тексты README.md для целевых репозиториев пользователя.
