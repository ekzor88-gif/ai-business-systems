# Контекст Выполнения (Execution Context)

## Назначение
Директория `context/` предназначена для хранения динамического контекста выполнения, истории сессий, промежуточного состояния (short-term memory) и данных, разделяемых между агентами во время выполнения пайплайна.

## Обязанности
- Управление сессионным контекстом и логом выполнения (execution log).
- Обеспечение интерфейса доступа агентов к общему состоянию (Blackboard pattern / Shared Context).
- Сериализация и десериализация текущего состояния сессии для возможности приостановки и возобновления работы.

## Будущие модули
- `session.py`: Класс сессии, хранящий метаданные пользователя, текущий шаг и стек вызовов агентов.
- `memory.py`: Интерфейс кратковременной памяти сессии для накопления промежуточных артефактов.
- `state_manager.py`: Компонент для сохранения состояния на диск и его восстановления.
