## 📌 Описание Проекта
Дипломный проект в рамках обучения в школе **MYFreedom**. Представляет собой современную SaaS-платформу для автоматизации работы склада, отслеживания остатков, автоматического анализа дефицита с помощью ИИ-агентов и автоматического закупа товаров у поставщиков.

---

## 🎯 Решаемая Проблема
- **Ручной контроль остатков**: Риск задержек поставок и упущенной выручки из-за несвоевременного заказа отсутствующих товаров.
- **Низкая скорость аналитики**: Менеджеры тратят часы на выявление ликвидных/неликвидных позиций и составление заявок поставщикам.
- **Ошибки человеческого фактора**: Ручной перенос данных из таблиц в email-письма для поставщиков.

---

## 💡 Архитектурное Решение
- **Frontend App**: SPA-приложение на React 18 + Vite с отзывчивым UI (Tailwind CSS, Framer Motion, Recharts).
- **ИИ-Оркестрация (n8n)**: Интеграция с n8n через Webhooks. n8n выступает в роли умного бекэнда, который обрабатывает состояние склада, вызывает LLM для сбора аналитики и отправки email-заявок поставщикам.
- **Авто-Закупитель**: При достижении критического порога остатков ИИ-агент автоматически формирует и отправляет заявку поставщику.

---

## 📊 Измеримые Результаты
- **Сокращение времени заказа**: Создание и отправка заявки поставщику занимает 5 секунд вместо 15-20 минут ручной переписки.
- **Авто-мониторинг 100% остатков**: ИИ-аналитика выявляет критические дефициты в реальном времени.
- **Успешная защита диплома**: Проект полностью реализован, протестирован и защищен в школе MYFreedom.
